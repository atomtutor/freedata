# 🎉 우리반 데이터쇼

설문 데이터를 "분석 결과"가 아니라 **우리 반 예능 코너**처럼 보여주는 웹앱입니다.
버튼 하나 누를 때마다 효과음·애니메이션·카운트업 숫자가 터지면서
교실 뒤에서 봐도 "오~" 소리가 나오는 걸 목표로 만들었습니다.

설치나 서버 실행 없이 `index.html`을 더블클릭하면 바로 실행됩니다.

**어떤 설문지를 올려도 컬럼명을 그대로 자동 인식**합니다. (컬럼명이 "닉네임/급식만족도"든 "참가자명/행복지수"든 상관없이 범주형·수치형을 자동 분류해서 화면을 그 컬럼명으로 자동 구성합니다.)

**화면은 2단계로 구성**되어 있습니다: ① 데이터를 불러오는 입력 화면 → **[📊 분석 시작하기]** 클릭 → ② 탭(데이터 한눈에/가설 대결/닮은꼴 찾기)이 있는 분석 화면. 분석 화면 좌측 상단 **[◀ 데이터 다시 불러오기]**로 언제든 입력 화면으로 돌아가 데이터를 바꿀 수 있습니다.

## 📁 폴더 구조

```
project/

├── css/

│   ├── layout.css        # 레이아웃, 탭별 스타일
│   └── animations.css    # 스탬프·컨페티 애니메이션
├── js/
│   ├── state.js           # 전역 상태 관리
│   ├── sound.js            # Web Audio 효과음 모음
│   ├── data.js              # 데이터 파싱 + 샘플 데이터(SAMPLE_DATA) 내장
│   ├── tab-battle.js       # 탭1: 가설 대결
│   ├── tab-overview.js    # 탭2: 우리반 한눈에
│   ├── tab-match.js        # 탭3: 닮은꼴 찾기

└── data/
    └── survey_fake_data.csv   # 테스트용 가상 데이터(100명, 백업 업로드용)
```

## ▶️ 실행 방법

1. `project` 폴더 전체를 다운로드/압축 해제
2. `index.html`을 더블클릭해서 브라우저로 열기 (Chrome 권장)
3. 별도 서버 설치나 실행 없이 바로 동작합니다. (모든 스크립트가 일반 `<script>` 태그로 작성되어 있고, 샘플 데이터도 파일 안에 내장되어 있어 `file://`로 열어도 fetch 에러가 나지 않습니다.)

인터넷 연결이 있으면 Pretendard 웹폰트가 자동으로 적용됩니다(CDN). 오프라인이어도 시스템 기본 폰트로 정상 작동합니다.

## 📊 데이터 입력 4가지 방법

| 방법 | 절차 |
|---|---|
| **구글 시트 링크** | 시트 공유 설정을 **"링크가 있는 모든 사용자(뷰어)"**로 바꾼 뒤, 그 공유 링크를 입력창에 붙여넣고 **[🔗 링크로 불러오기]** 클릭 |
| **복사·붙여넣기** | 구글 시트에서 **1행(헤더) 포함 전체 범위**를 드래그 → Ctrl+C → 앱 상단 텍스트박스에 Ctrl+V → **[📋 붙여넣은 내용 적용하기]** 버튼 클릭 |
| **CSV 파일 업로드** | 구글 시트 → 파일 → 다운로드 → CSV → **[CSV 파일 불러오기]** 버튼으로 선택 |
| **샘플 데이터 로드** | **[샘플 데이터 로드]** 버튼 → `data/survey_fake_data.csv`(100명 가상 데이터)를 즉시 불러옴. 리허설/시연용 |

> ⚠️ 붙여넣은 뒤에는 반드시 **[적용하기] 버튼**을 눌러야 반영됩니다. (자동 감지도 시도하지만, 버튼을 눌러야 100% 확실하게 반영됩니다.)

### 🔗 구글 시트 링크로 불러오기

- 공유 링크(`.../edit?usp=sharing`, `#gid=...` 포함된 형태 등)를 그대로 붙여넣으면 됩니다. 내부적으로 CSV 내보내기 링크로 자동 변환해서 가져옵니다.
- **필수 조건**: 시트 공유 설정이 **"링크가 있는 모든 사용자 - 뷰어"**로 되어 있어야 합니다. 비공개 상태면 실패합니다.
- 이 방식은 **매번 복사·붙여넣기 하지 않고, 버튼만 다시 눌러서 최신 응답으로 갱신**할 수 있다는 장점이 있습니다. 수업 중 응답이 계속 들어오는 상황에 특히 유용해요.
- GitHub Pages처럼 `https://`로 서빙되는 환경에서는 안정적으로 동작합니다. 혹시 실패하면 옆의 **[새 탭에서 확인]** 버튼을 눌러 열리는 화면의 내용을 전체 복사(Ctrl+A → Ctrl+C)해서 붙여넣기 칸에 넣는 방법으로 항상 우회할 수 있습니다.

### 🤖 컬럼 자동 인식 (범주형 / 수치형)

데이터를 불러오면 **컬럼명을 고정하지 않고** 아래 규칙으로 자동 분류합니다. 분류 결과는 데이터 입력창 아래 **"🏷️ 범주형 / 🔢 수치형"** 미리보기에서 바로 확인할 수 있어요.

| 규칙 | 분류 |
|---|---|
| 헤더에 "타임스탬프/날짜/시각" 포함 | 시간 컬럼 → 분석에서 제외 |
| 헤더에 "닉네임/이름/성명" 포함 | 식별자 컬럼 → 닮은꼴 찾기의 이름표로 사용 |
| 값의 90% 이상이 숫자 | **수치형** → 가설 대결의 "지표", 우리반 한눈에 평균/히스토그램, 닮은꼴 찾기 거리 계산에 사용 |
| 숫자가 아니고 고유값이 2~8개 | **범주형** → 가설 대결의 "주어", 우리반 한눈에 비율 그래프에 사용 |
| 그 외(자유서술형처럼 값이 너무 다양함) | 분석에서 제외 (원본 데이터에는 남아있음) |

식별자 컬럼(닉네임 등)을 못 찾으면, 값이 전부 고유한 텍스트 컬럼을 자동으로 이름표로 채택하고, 그마저 없으면 "건1, 건2…"(또는 사람 데이터로 판별된 경우 "명1, 명2…")로 표시합니다.

### 🙋 사람 데이터 / 🧾 일반 데이터 자동 구분 ("명" vs "건")

헤더에 "닉네임/이름/성명"처럼 사람을 가리키는 이름이 있으면 이 데이터를 **사람에 대한 응답**으로 보고 화면 곳곳의 단위를 **"명"**으로 표시합니다. 반대로 그런 헤더가 없다면(예: 카페 음료 데이터셋처럼 사물에 대한 데이터) 중립적인 **"건"**으로 표시합니다. 이 판별은 자동으로 이뤄지며, 별도 설정이 필요 없습니다.

가설 대결·우리반 한눈에·닮은꼴 찾기의 드롭다운/카드는 이 분류 결과를 기반으로 **매번 자동 생성**되므로, 완전히 다른 설문지를 올려도 코드 수정 없이 바로 동작합니다.

## 🗂️ 탭별 기능

### 1. 가설 대결
- `[범주형 값] 은(는) [지표]가(이) 높다(많다)!` 문장을 드롭다운으로 조합 (드롭다운은 자동 인식된 컬럼으로 매번 새로 구성됨)
- **지표는 두 종류 중에서 고를 수 있어요**:
  - **수치형 컬럼** (예: 칼로리, 급식만족도) → 두 그룹의 **평균**을 비교
  - **다른 범주형 컬럼의 특정 값** (예: 아침형 그룹의 "P" 비율) → 두 그룹에서 그 값이 나오는 **비율(%)**을 비교. 예: `아침형은 P가 많다!`, `J는 저녁형이 많다!`, `커피는 차가 많다!`(범주형 컬럼이 2개 이상일 때)
  - 주어로 고른 컬럼 자기 자신은 지표 목록에서 자동으로 빠집니다 (자기 자신과 비교하는 것을 방지)
- **[확인]** 클릭 → 두구두구 효과음 → 결과 공개
- 화면 왼쪽엔 큰 ⭕/❌(또는 🤝 무승부) 이모지, 오른쪽엔 두 그룹 값 막대그래프 (범주형 지표는 %로 표시)
- 두 그룹 값이 반올림 기준으로 같으면 자동으로 **무승부(🤝)** 처리
- 컬럼명이 "~수"로 끝나는 수치형(반려동물수 등)이거나, 범주형 비율 비교일 때는 "높다" 대신 "많다"로 자동 표기

### 2. 우리반 한눈에
- 자동 인식된 범주형·수치형 컬럼 전체를 카드 슬라이드로 한 장씩 확인 (◀ 이전 / 다음 ▶)
- 항목마다 요약 숫자 + 막대 시각화 제공
- **수치형 컬럼의 값 종류가 10개를 넘으면(예: 칼로리처럼 값이 세밀하게 갈리는 경우) 값 하나하나가 아니라 "0~50", "50~100"처럼 5~7개 구간으로 자동으로 묶어서 보여줍니다.** 값 종류가 10개 이하인 경우(예: 1~10점 척도)는 지금처럼 값별로 그대로 보여줘요.

### 3. 닮은꼴 찾기
- **[매칭 시작!]** → 계산 효과음 → 1·2·3위 카드가 잠긴 채 등장
- 카드를 하나씩 클릭하면 순위별 효과음(3·2위는 긴장감, 1위는 팡파르)과 함께 결과 공개
- 자동 인식된 **모든 수치형 컬럼**을 정규화해서 유클리드 거리로 가장 비슷한 두 사람을 계산
- 이름표는 자동 인식된 식별자 컬럼(닉네임 등) 기준

## 🎨 커스터마이징 팁

- **색상 변경**: `css/theme.css` 상단 `:root{ --pink, --teal, --yellow, ... }` 값만 바꾸면 전체 톤이 바뀝니다.
- **효과음 변경**: `js/sound.js`에서 각 효과음(ding, buzz, drumroll, shuffle, suspense, fanfare, tie)의 주파수/길이를 조정할 수 있습니다.
- **자동 인식 규칙 조정**: `js/data.js`의 `ID_HEADER_RE`(식별자 헤더 패턴), `TIME_HEADER_RE`(시간 헤더 패턴), `detectSchema()`의 범주형 판정 기준(고유값 2~8개, 숫자 비율 90%)을 조정할 수 있습니다.

## 🔧 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| 화면이 하얗게 뜨고 아무것도 안 됨 | 브라우저 콘솔(F12) 확인. 오래된 캐시 문제면 새로고침(Ctrl+Shift+R) |
| 붙여넣었는데 인원수가 안 바뀜 | **[적용하기] 버튼**을 눌렀는지 확인. 1행(헤더)을 포함해서 복사했는지 확인 |
| 구글 시트 링크 불러오기 실패 | 시트 공유 설정이 "링크가 있는 모든 사용자(뷰어)"인지 확인. 그래도 안 되면 [새 탭에서 확인] 버튼으로 연 화면 내용을 전체 복사해서 붙여넣기 칸에 넣기 (실패 안내는 링크 입력창 바로 아래에 뜨며, 입력창은 자동으로 비워집니다) |
| CSV 파일 업로드 시 한글이 깨짐 | 자동으로 UTF-8/EUC-KR(엑셀 기본 저장 인코딩)을 판별해서 읽으므로 대부분 자동 해결됩니다. 그래도 깨지면 다른 인코딩일 수 있으니 복사·붙여넣기 방법을 이용해 주세요 |
| 소리가 안 남 | 브라우저 자동재생 정책 때문에 페이지에서 한 번 클릭(버튼 클릭 등)이 있어야 소리가 납니다. 첫 클릭 이후부터는 정상 작동 |
| 폰트가 기본 폰트로 보임 | 인터넷 연결 확인 (Pretendard는 CDN에서 불러옵니다). 오프라인이어도 기능은 정상 동작 |

## 🔒 사용 시 유의사항

- 닉네임 문항은 **본명 대신 재밌는 별명**을 쓰도록 학생들에게 미리 안내해 주세요. 닉네임이 그대로 화면(특히 "닮은꼴 찾기")에 노출됩니다.
- 진행 전 교사가 응답 데이터를 가볍게 훑어보고, 민감하거나 부적절한 내용이 없는지 확인하는 것을 권장합니다.
